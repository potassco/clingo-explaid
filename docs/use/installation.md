# Installation

The *clingo-explaid* system is available in [PyPI](https://pypi.org/project/clingexplaid/).
Install it using pip by running the following command in your terminal:

```console
pip install clingexplaid
```

-----

A successful installation will make the `clingexplaid` command available in your terminal. You can check the installation by running:

```console
clingexplaid -h
```

This will display the help message with available options and usage instructions, for detailed CLI information refer to the [CLI documentation](../reference/cli/index.md).
