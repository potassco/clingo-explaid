# Unsatisfiable Constraints

Unsatisfiable constraints are the constraint rules that fire for an unsatisfiable ASP program.
Identifying these can be very helpful for understanding why the program is unsatisfiable in particular in debugging scenarios.
`clingexplaid` provides an easy way to find these for any given ASP program.
