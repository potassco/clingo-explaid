# Clingo-Explaid

!!! info
    *clingo-explaid* is part of the [Potassco](https://potassco.org) suite.

*clingo-explaid* is an API to aid the development of explanation systems using
[clingo](https://potassco.org/clingo/). It provides tools for computing
Minimal Unsatisfiable Subsets (MUS), unsatisfiable constraints, and more.

## Installation

*clingo-explaid* can be installed with `pip`:

```bash
pip install clingexplaid
```

It requires `python >= 3.10` and `clingo >= 5.7.1`.

To get started, head to the [Quick Start Guide](use/quick-start.md).
